YC S26 (Ejemplo) DevTools AI Safety

El Problema

El "Salvaje Oeste" de los Agentes de IA

  • Dar acceso a herramientas del sistema (bash, lectura/escritura de archivos) a modelos de IA es un riesgo empresarial inaceptable.
  • La gobernanza actual en IA suele ser opcional, frágil o una idea de último momento.
  • Un solo fallo de permisividad = fuga de datos, eliminación de infraestructura o multas regulatorias.

💡 Insight: Las empresas no necesitan agentes más "inteligentes"; necesitan agentes que puedan controlar con certeza absoluta.

La Solución

Gobernanza "Fail-Closed" (Fallo Seguro)

  • Una puerta de política (policy gate) no opcional antes de cada llamada a herramientas integradas.
  • Si hay errores de red, respuestas HTTP inválidas, malformadas o decisiones de política desconocidas: el sistema se convierte en REVIEW o BLOCK.
  • Nunca ALLOW por defecto. El proveedor del modelo es reemplazable; la seguridad no.

Cómo Funciona

Arquitectura Simple y Robusta

  • Enrutamiento por solicitud: Anthropic, Ollama, OpenAI, Groq, vLLM, etc. Usa --task para rutas deterministas en CI.
  • Ciclo de decisión: Modelo → Loom Runtime → DevMind (evalúa riesgo) → Ejecución de herramienta.
  • Trazas de auditoría legibles: Registra herramienta, decisión, puntuación de riesgo, resultado e ID de sesión. Nunca expone el payload de la acción.

Experiencia de Desarrollador (DX)

Construido para Producción

Escrito en Go 1.22+: Rápido, seguro, con un solo binario y sin dependencias pesadas.

$ loom init
$ export OPENAI_API_KEY=sk-...
$ loom doctor
$ loom run "revisa el README y corrige errores"
$ loom run --task security_review "analiza este cambio de Terraform"

Configuración local por proyecto (loom.config.json) con soporte nativo para cualquier API compatible con OpenAI.

Visión y Hoja de Ruta

Hacia el Plano de Control Empresarial

  • Hoy: Runtime local seguro con gobernanza DevMind integrada y trazas de auditoría.
  • Próximos Pasos: Cliente MCP stdio, integración con GitHub Actions, almacenamiento de auditoría centralizado, flujos de aprobación humana y el Enterprise Control Plane.
  • La Oportunidad: La infraestructura de gobernanza será el mayor habilitador (y cuello de botella) en la adopción de agentes de IA B2B a escala.
